# Perfect Profile Spatial Clue Preview - Fixed GitHub Build

This build is intentionally self-contained.

## Upload
1. Delete or replace the existing `index.html` in the GitHub repository.
2. Upload this package's `index.html` to the repository root.
3. Commit changes and wait for GitHub Pages to redeploy.
4. Hard refresh the Pages URL with Ctrl+F5.

The level JSON, CSS and JavaScript are embedded inside `index.html`, so it does not depend on `app.js`, `style.css`, or `data/levels.json`.
