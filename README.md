# Perfect Profile — Theme Level Preview

Static GitHub Pages preview generated from `Perfect_Profile_100_Levels_Theme_Designed_With_Level_Map(1).xlsx`.

## Upload to GitHub Pages

Upload the **contents of this folder** to the repository root so `index.html` is visible at the top level. Then open **Settings → Pages → Deploy from a branch → main → /(root)**.

Required runtime files:

- `index.html`
- `style.css`
- `app.js`
- `data/levels.json`

Optional reference files:

- `source-data.xlsx`
- `standalone-preview.html`
- `.nojekyll`

## Features

- 10 chapter themes and 100 levels
- Full clue list and deduction-flow view
- Interactive grid with drag/click placement
- Complete answer keys and level validation
- Case question and final reveal
- Level, logic, QA and art-scope metadata
- Local progress save, export and import
- Direct links such as `?level=42`

For a local test without a web server, open `standalone-preview.html`.
